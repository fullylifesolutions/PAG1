# PAG LITE - Profilo di Appartenenza al Gruppo

**Versione Lite - Solo Profili**

Progressive Web App (PWA) per la gestione e l'analisi dei profili di appartenenza al gruppo.

## 🎯 Cos'è PAG Lite?

PAG Lite è la versione **semplificata** dell'app PAG, dedicata esclusivamente alla gestione dei **Profili di Appartenenza al Gruppo**.

Questa versione è ideale per chi segue un percorso Fullylife focalizzato sulle dinamiche di gruppo **senza** la Struttura Psicofisiologica Primaria (SPP).

## ✨ Funzionalità

### ✅ Incluse:
- 📝 Note Generali
- 👥 Profili di Appartenenza (Lavoro, Famiglia, Altro)
- 📊 Grafici radar & Timeline
- 📤 Export profili (singolo/multiplo)
- 🛡️ Backup completo
- 📅 Gestione appuntamenti
- 📖 Manuale utente

### ❌ NON Incluse:
- Struttura Psicofisiologica Primaria (SPP)
- PDF approfondimento SPP

## 🆚 Differenze con PAG Completo

PAG Lite è pensato per chi segue un percorso **solo sui profili di gruppo**, senza SPP.
